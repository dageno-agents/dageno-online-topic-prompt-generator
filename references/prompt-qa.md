# V3 Prompt QA

runtime/qa.mjs performs deterministic integrity checks. runtime/pipeline.mjs invokes independent semantic review. Run node runtime/cli.mjs qa panel.json. Neither a prose instruction to run QA nor a model-authored passed flag is sufficient validation.

Read [the current V3 contract](v3-validation.md) before executing this step.
Legacy V2 quotas, numeric acceptance thresholds and schemas are retired.

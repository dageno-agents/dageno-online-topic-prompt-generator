# V3 CSV Output

The import format is exactly topic,prompt,regions,language. UTF-8 BOM, CRLF, correctly quoted cells. Default export is the independently reviewed, serviceable brand-competition list. Use --dataset benchmark, citation or content for separate lists; full metadata remains in JSON.

Read [the current V3 contract](v3-output-contract.md) before executing this step.
Legacy V2 quotas, numeric acceptance thresholds and schemas are retired.

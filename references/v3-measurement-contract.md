# V3 Measurement And Uncertainty

## A Panel Is Not A Census
Generated prompts are research-designed questions, not a log of real users' exact queries.
Evidence can show plausible demand without measuring frequency. Keyword volume is not conversational prompt frequency.
No multiplication of SEO volume by sampled AI visibility proves real AI impressions.

## Denominators
Keep four dimensions separate: intent unit, coverage scope, content/monitoring pool and benchmark membership.
Core KPI: eligible brand_core monitoring units.
Generic category benchmark: ALL eligible benchmarkMember monitoring units in the same confirmed L3, including brand_core.
Whitespace: opportunity view, not automatically a service KPI failure.
Adjacent or out-of-scope demand: separate reference panels.
Knowledge/source citation monitoring must not be reported as identical to provider recommendations.

A provisional L3 panel is project-local. Do not compare different brands or historical taxonomy versions without an approved shared mapping.
Uniform weighting is a transparent panel convention, not a claim of equal real demand.
Any demand-weighted version needs independent measured weights and a disclosed data source.

## Evidence Labels
serviceability: evidence_supported / inferred / not_verified.
demand: multiple_publisher_signals / plausible_inference / reported_question_needs_source_review.
No model confidence score can establish a calibrated probability.
Search snippets and vendor claims retain their weaker evidentiary status.

## Entity Pilots
Default: not_run, mentionLikelihood=null.
For a separately authorized pilot, retain prompt, requested/returned model, time, locale, raw response, relevant entity list and sample size.
Count ANY relevant entity, not target-brand presence. A poor target result must not change panel inclusion.
Separate entity-elicitation rate from relevance, target visibility, source citations and sentiment.
An OpenRouter API response is not equivalent to the consumer ChatGPT/Gemini/AI Overview product.
Do not infer measured probability from a tiny sample; report numerator/denominator and uncertainty.
Never remove a genuine question because a single run names no brands.

## Versioning
Stable IDs derive from semantic market/object/buyer/job/constraint/sub-intent identity, not row number, language or Topic order.
Wording changes are recorded separately. Repeated generations may still choose different semantic descriptions, so IDs alone do not solve all semantic migration.
Version diff lists retained, wording-changed, added and removed units; review before replacing a panel.
Unmatched semantic equivalents need human review; do not automatically merge by fuzzy similarity.
Report a common-panel trend alongside expanded-panel results. Do not rewrite old denominators.
